## Retrospective delinquency survival

The first 10,000 Taiwan rows yielded **50,973 person-month rows**, **2,801** first recorded two-month delinquency events and **7,199** censored records. A Cox model using only nonmonthly baseline covariates had **in-sample concordance 0.6521**. The discrete monthly hazard logistic model had **in-sample AUC 0.7091**. Kaplan–Meier survival without the proxy event at month 3 was **0.7494** for limits below 100k and **0.8808** for limits at least 100k. The proportional-hazards diagnostic for `EDUCATION` had p **0.0468**, a reason to review that assumption. This is *time to observed repayment-status threshold*, not time to default, and both model metrics are in-sample. Comparing their AUC with the static next-month default model would mix endpoints and future information, so no such superiority claim is made.

Limits: the sign-off log is a local file with a SHA-256 hash chain. The chain shows an edited, reordered or deleted earlier line.
